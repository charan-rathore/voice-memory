# Bounded requested-fact support repair

This private slice checks the existing generic excerpt-only fallback. A citation whose bytes match does not establish that its passage contains the requested role, identifier type, quantity or printed weight unit. Existing claims resolution and physical ownership derivation are not changed.

Supported bounded relations: explicit receiver/recipient/received-by/delivered-to labels, tracking/carrier identifier labels, labeled counts and natural number-plus-count-noun phrases, and explicit numeric weight plus printed units. An explicit requested weight unit must match the printed unit; no conversion is inferred. Explicit not-recorded/not-specified/not-assigned wording supports an absence excerpt, not a populated value. Missing fields retain closest passages for review but cannot retain clean positive support.

Only simple explicit Order/Parcel/Shipment identifier blocks are text-scoped inside a quote; this is not a record-ownership resolver for arbitrary documents, physical layouts or unknown namespaces. Prefix negation must not be dropped before a label. The same-prefix separate-file, same-document two-order, missing-ID, explicit positive, explicit absence, missing-unit and unrelated-conflict coverage controls are separate assertions.

Known limits: the deterministic grammar is intentionally bounded, not a general semantic parser. Unsupported paraphrases may over-refuse. The repair does not settle version authority, global mixed-owner admission, model-generated synthesis, arbitrary same-document ownership, or issuer identity. Full production qualification, independent review and release authority remain separate gates.

Review hardening additionally rejects bounded negated/invalid/unfinished role wording, preserves explicit comma-separated receiver names, matches full identifier token boundaries in unlabeled fallback text, and requires requested gross/net or open/closed/approved/dispatched modifiers inside the same candidate clause. This remains a narrow deterministic relation check, not a general proof that all modifiers or clauses are bound correctly.

Consumer follow-through: actual supported evidence is now narrowed to exact
field fragments, including explicit Record headings, before typed/extractive
consumption. Public deterministic fact/section/hybrid rescues and optional
semantic rescue cannot replace this bounded policy, including its refusals.
The voice adapter applies the same policy after external retrieval without
promoting an insufficient result. Normalized spaced/dash identifier forms stay
bound to the original printed textual root. Default and external-adapter SSE
checks inspect returned text/retained turns, not real TTS or captured audio.

Carrier-reference and tracking labels are distinct; a differently labelled ID
is not an implicit alias. Negated relations and multiple same-kind counts in
one clause refuse for review. This can reduce yield. Account-owner, retention,
unknown property/paraphrase, arbitrary physical ownership and whole-workspace
coverage remain outside this bounded path. Whole-set admission is separate.

Literal identifiers preserve their printed separators. Normalized speech aliases
resolve only when one distinct printed root exists in the full bundle, including
roots outside retrieved evidence; separator collisions refuse. Existing ambiguous
retrieval remains ambiguous even for a literal query and is never promoted by
this policy. The current root inventory is a full source-text scan on recognized
questions, not a cached identity index or a production scale qualification.

Current-main reconciliation keeps the released subject/field identifier resolver
for non-record queries. Only a requested field plus an explicit printed textual
record namespace selects this record-local path, including unknown values that
must refuse. Voice dispatch uses the same normalized query that retrieval uses.
Ordinary numbered prose such as "unit 27" does not become a normalized record
alias without a printed root namespace. Existing small-count ingest coverage
failed on the earlier candidate and passes after this correction.
