## Interpretation and evidence path

The default opaque question now has an optional model-reviewed interpretation path when document reading is enabled and the current document-set/model/provider consent passes. Two blind question reconstructions must partition every original non-whitespace character identically. The server derives requirement IDs and keeps the full original. This is structural/source coverage, not proof of meaning.

The document reader and a separate blind full-source reconstruction produce candidate claims. Reconciliation keeps original request identities and agreeing outcome statuses. Distinct support from either read cannot silently disappear. When one proposal's support contains the other's, an existing wording can be selected, but the final audit must still judge every independent claim against it. Otherwise novel claims are retained. All displayed claims pass unchanged exact source/ownership/span admission, then full-source/per-claim audit. Missing coverage judgments fail closed. Contradictory meanings remain an audit risk; no general reliability claim is made.

OpenRouter JSON mode is now explicit. Requests have provider token-price ceilings and optional route pinning. Provider cost receipts cannot be understated by token estimates. Optional reasoning-off is a tested DeepSeek profile, not a universal setting: Gemini rejects reasoning-off. Typed cloud reading uses a90second UI timeout; ordinary lookup retains20seconds. Live host/proxy deadline compatibility remains unverified.
