Where it stands

A buildathon prototype on fictional documents, described without rounding up.

Works now

  • Questions by voice or text over the documents in a session
  • Proposed, superseded and still open, tracked per value
  • Short spoken answers built from the record
  • PDF, Word, image and text uploads, with the cited line on the original page
  • Lab results compared across synthetic reports, refusing when units or patients differ

Next

  • An uncut recording of a live call
  • A test set of real, messy documents
  • Search that understands paraphrases: today 29% of reworded questions find the passage, vs 91% literal
  • Durable, encrypted storage

Not claimed

  • Accuracy on documents we haven't tested
  • That a rule can't misread a sentence
  • Fitness for real medical or personal records
